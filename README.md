## Projects and test documentation

### File Upload Testing

Manual testing of the File Uploader on The Internet practice application. The project covers file selection through the Choose File button and upload area, drag-and-drop, different file types, and handling an upload attempt without a selected file.

**What I did**

- Created a test plan and recorded questions about the application's behavior.
- Prepared a checklist and test data.
- Executed functional positive and negative test scenarios.
- Created a test run and documented expected and actual results.
- Reported 3 bugs with reproduction steps, expected and actual results, severity, priority, environment details, and screenshots.
- Used the Chrome DevTools Network tab to investigate failed requests and verify HTTP 500 responses.

**Recorded results**

The test run contains 17 checklist items. Ten passed, three failed, and four were not run. The failed checks cover uploading a file selected through the upload area, uploading a file using drag-and-drop, and submitting an upload without a selected file.

**Investigation example**

In BR-FU01, uploading a file selected through the upload area produced an Internal Server Error. I used the Network tab to verify the HTTP 500 response and included the reproduction steps and screenshots in the report.

Open `Test Run AM_13.08` for the execution results and `Bug Reports` for the three documented failures.

### Alo Yoga Web Testing

Manual testing of the Alo Yoga e-commerce website, focusing on the home page, registration, sign-in, and shopping cart. For this practice project, requirements were derived from the publicly available interface and observed behavior.

**What I did**

- Analyzed the selected functionality and documented derived functional requirements.
- Created a test plan defining the scope and testing approach.
- Created a Requirements Traceability Matrix (RTM) linking requirements to test cases.
- Created and executed test cases for positive, negative, and boundary scenarios.
- Prepared test data for account and shopping cart checks.
- Documented test results in the test run and summary sheets.
- Identified project risks and documented mitigation measures.
- Assessed test cases as candidates for future automation.

**Testing areas**

- Home Page
- Registration
- Sign In
- Shopping Cart

**Recorded results**

The workbook contains 46 test cases and records two test runs, in Chrome and Microsoft Edge. Each run reports 46 passed, 0 failed, 0 blocked, and 0 not run. The records were prepared retrospectively, and execution dates were not recorded.
